# 🚌 BusGo App

BusGo is a modern bus booking and tracking application designed to help users search, book, and manage bus tickets easily. The app provides a smooth and user-friendly experience for passengers and transport operators.

---

## 🚀 Features

- 🔍 Search buses by source and destination
- 🪑 Seat selection system
- 🎫 Online ticket booking
- 📍 Live bus tracking
- 👤 User authentication & profile management
- 💳 Secure payment integration
- 📅 Booking history
- 🔔 Real-time notifications
- 🌙 Responsive and modern UI
